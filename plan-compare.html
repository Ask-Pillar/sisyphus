总览

v1 旧计划

范围 Memory Tree 4 Phase
设计哲学 增量式功能模块
视角 组件级，从 TreeStore 自底向上
文件 tree.json 单文件全量
进程模型 未定义
命中率目标 56% → 70%

v2 新架构

范围 完整 MCP Server + 双路径检索 + Sleep Pipeline

文件 tree/ 目录拆小文件 + _lock/ 锁

命中率目标 58% → 85%+ top-1
