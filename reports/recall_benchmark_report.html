五、四次迭代详解

v1：两阶段纯 Embedding 重排

公式：BM25 top-20 → 按 Embedding 余弦降序重排

结果：@1=50%，@3=83%。@3 与 Embedding 持平，但丢掉了 BM25 的 @1 精确匹配优势。

原因：Embedding 在 4 个 query 上选了语义更匹配但 label 不同的项（如 "精炼层保存什么类型的记忆？" 选 Refined_1 而非 Refined_0）。余弦差 0.02～0.15。

v2：余弦差阈值决胜（失败）

公式：余弦差 < 0.05 时 BM25 作为 sort 第二关键字决胜

结果：无变化，@1=50%，@3=83%。

失败原因：Python 的 sort(key=...) 第二关键字只在第一关键字完全相等时才生效——浮点数余弦几乎不可能相等。所以 BM25 哨兵码从未被触发。

v3：加权融合（成功 ✓）

公式：blended = 0.75 × cos + 0.25 × (bm25 − min) / (max − min)

结果：@1=56%，@3=86%，全面超越两种基线。

原理：BM25 信号归一化后以 25% 权重持续注入——始终参与排序，不依赖阈值触发。余弦主导语义排序，归一化 BM25 在余弦接近时提供精确匹配偏置。

六、结论

  • 两阶段架构验证通过：BM25 宽召 + Embedding 精排 + 25% BM25 融合是最优结构。
  • 最优融合权重 w=0.25：经验扫描 0.0～1.0 确认，0.25 时 @3 达到最高点 86%。
  • 当前 @1=56% 是模型能力天花板：纯 Embedding @1=50%。要突破 56% 需升级 embedding 模型或修正 benchmark label 偏置（4 个 query 中 Embedding 语义选择实际比 label 更准确）。
  • v3 获胜代码：retrieval.py 中嵌入精排阶段的 blended score 计算。
