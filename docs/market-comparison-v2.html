二、值得借鉴的设计

🟢 Hermes — Frozen-snapshot + 硬上限

记忆在 session 开始时捕获冻结，中途不变 → 保留 LLM prefix cache。Sisyphus PERSIST 层可直接套用。MEMORY.md 硬上限 2,200 字符防膨胀。

🟢 OpenHuman — 密封(seal)管道

L0 缓冲攒够 → L1 密封成摘要 → 级联向上。Sisyphus Dream 完全同构：RAW ≥ N → Dream 密封成 REFINED。按实体热度动态建树 = 我们的 project 字段。

🟣 agentmemory — 可视化标杆

端口 3113 的内置 Viewer：实时观察流 + Session explorer + 记忆浏览器 + 力导向知识图谱 + Health dashboard。Sisyphus 可视化直接对标这个。

🟢 Claude Code — 关闭式类型 + 蒸馏摘要

4 种类型（design/learn/fix/debug）防 tag 蔓延。Session memory 不求全量回放，只要"继续工作所需的最小结构"。Compact 重建工作语义而非漂亮摘要。

三、可视化模块规划 P2-3

sisyphus-viewer — 零依赖静态 HTML Dashboard

模块路由技术功能
记忆浏览器/browserHTML+CSS按 type/tag/project/importance 过滤，时间线视图，BM25 实时搜索
知识图谱/graphCytoscape.js力导向布局，节点=记忆，边=refined_by/links/evidence，按类型着色
Pipeline 监控/pipelineChart.jsRAW→REFINED 流转，Dream/Compress 历史，各层数量仪表盘
健康监控/health纯文本+图表各层记忆数，总 token，上次 Dream 时间

三种交付方式

A: HTTP server   → python3 -m sisyphus.viewer --port 3113
B: MCP 工具       → memory_dashboard → 返回 HTML blob → send-wechat
C: 静态导出       → python3 -m sisyphus.export.dashboard > dash.html

推荐 B+C：B 给微信，C 给本地。纯静态 HTML，零后端。
