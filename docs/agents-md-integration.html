## Sisyphus Memory (auto-injected)

Before EVERY response, inject relevant memory context.
Memory layers: PERSIST (always) → HOT (7d) → CODE (on demand) → COLD.

### Before each turn:
Run before_turn() to get relevant memories:
  PYTHONPATH=src python3 -c "
  from sisyphus.memory.context import AgentMemory
  from sisyphus.memory.store import MemoryStore
  store = MemoryStore(Path.home() / '.omo' / 'memory')
  mem = AgentMemory(store)
  print(mem.before_turn('CURRENT_QUERY', max_chars=4000))
  "
The <sisyphus_context> block contains lessons/decisions/patterns
from past sessions. Reference them if relevant.

### After each turn (when significant):
Record decisions, patterns, or bugs:
  python3 .omo/scripts/memory.py record lesson "title" \
    --tags "relevant" --content "what happened"

### MCP tools (when connected):
memory_stats | search_memory | write_memory | run_pipeline
