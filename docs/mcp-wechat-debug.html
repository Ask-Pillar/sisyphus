  1. MCP Server 启动失败 根因 #1

    # 72-76:  _handle_context v1 ✅

    修复：删除重复 handler + 孤儿代码，24 行删除，292 tests 全通过。

  2. Bridge 固定传空 mcpServers 根因 #2

    推测根因 #3 — sdk.mcp.add 静默失败

    opencode 源码 packages/opencode/src/acp/agent.ts 1147-1185 行：

    await this.sdk.mcp.add(
  { directory, name: key, config: mcp },
  { throwOnError: true },
).catch((error) => {
  log.error("failed to add mcp server", { name: key, error })
})

    可能原因：

    • ACP session 复用：每次 resume ses_1c24fc596ffe962zwQMnxEOxIR，旧 session 可能缓存了"无 MCP"状态

    • ACP 协议版本：sdk.mcp.add 端点可能不被当前协议版本支持
    • 权限/沙箱：ACP 进程无法访问 disk-demo 目录
