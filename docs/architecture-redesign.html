当前架构 vs 目标架构

改前 · 单一检索

before_turn(query)
  │
  └─ retriever.retrieve()
       ├─ MOC type 分类
       ├─ Refined 优先
       ├─ RAW BM25/TF-IDF
       └─ decay 排序 → top_k
            ↓
    <sisyphus_context>...

所有来源混在一起，无配额，无场景

改后 · 分层组装

assembler.assemble(query, scene)
  │
  ├─ PERSIST(frozen) → 2000 chars
  ├─ HOT(7天)       → 2400 chars
  ├─ SKILL(条件)     → 800 chars
  ├─ CODE(按需)      → 1200 chars
  └─ COLD(兜底)      → 剩余
       ↓
  拼接文本

每层独立配额，场景切换配额

Source 接口

class Source(ABC):
    name: str          # "PERSIST" | "HOT" | "SKILL" | "CODE" | "COLD"
    priority: int      # 组装顺序

    def assemble(self, query, budget) → list[TextBlock]: ...
PERSIST — frozen, 项目上下文 + 架构决策 + 核心模式。首次组装后缓存，后续 turn 直接用。
HOT — 7 天内，BM25 排序。优先召回。
SKILL — 按触发条件动态 append，匹配时才加载。
CODE — CodeGraphContext，函数签名/调用链/模块依赖。coding 场景激活。
COLD — 兜底，包装旧 ContextRetriever，剩余配额。
