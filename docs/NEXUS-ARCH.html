完整请求示例: "帮我审计这段 Go 代码"

① OpenCode → MCP → Nexus Core 路由引擎
② 路由查 agent_registry → hermes 有 security_audit 标签
③ 同时查 sisyphus → "上次 hermes 审 Go 漏了 SQL 注入"
④ Dream 分析调度历史 → "Go 审计 → opencode 更准"
⑤ 决策: 路由到 opencode（覆盖初始匹配）
⑥ 结果 → 零信任层 校验 → Extractor 提取 → 存入 sisyphus
⑦ 下次"审计代码" → 直接路由到 opencode（学习了）

蒸馏示例: 接入 Hermes 6 个月后

① Dream 分析 180 天 Hermes 审计日志 → 提取: "审计代码" = AST扫描 → OWASP → 依赖漏洞
② 工具链: bandit + trivy + safety 组合（成功率 94%）
③ Prompt 模板: "先查 subprocess,再查 eval,最后查网络请求"
④ → 存入 procedural/skills/code_security_audit.md
⑤ Hermes 变为可选 backup — Nexus 已学会独立执行
⑥ Hermes v2 发布 → 30 天对比观察 → 评估是否更新 internal 技能
