📌 PERSIST — 永不过期，每次 turn 无条件注入

入选: pinned=1 或 importance≥8 且 type∈(project_context,decision,pattern)

SELECT * FROM memories
WHERE status='active'
AND (pinned=1 OR (importance>=8 AND type IN ('project_context','decision','pattern')))
ORDER BY importance DESC;

不参与衰减，不占 top_k 配额，始终在 <sisyphus_context> 里。

🔥 HOT — 7 天窗口，优先检索

7 天内创建的活跃记忆，按衰减排序，排除 PERSIST 条目

SELECT *, importance * POW(0.5, days/180.0) AS score
FROM memories_fts WHERE memories_fts MATCH ?
AND status='active' AND pinned=0
AND created_at >= date('now','-7 days')
ORDER BY score DESC LIMIT 5;

❄️ COLD — 历史全文检索，衰减排序

超过 7 天的历史记忆，FTS5 全文匹配 + 180 天半衰期衰减

SELECT *, importance * POW(0.5, days/180.0) AS score
FROM memories_fts WHERE memories_fts MATCH ?
AND status='active' AND pinned=0
AND created_at < date('now','-7 days')
ORDER BY score DESC LIMIT 5;
