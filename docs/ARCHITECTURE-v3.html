🔄 完整检索流水线 — 双路径 + 四级降级

🌲 Path A — 树浏览（宽泛查询）
"有什么存储相关的？" / "Python有哪些用法？"
Query→ EC: 子树叶 max-score 匹配 L1→ 锁定子树→ 子树内 BM25 精排→ 杏仁核衰减→ 注入 Agent 上下文
适用: 短 query (< 3 token) · 模糊词 (有什么/哪些/怎么样) · 宽泛问题
🔍 Path B — 精确检索（具体查询）
"k1 参数默认值是多少？" / "Sisyphus有多少测试？"
Query→ PHR: MOC 类型匹配→ EC: 树限定搜索域→ CA3: BM25 全量粗召→ CA1: BCE 精排→ 杏仁核衰减→ 注入 Agent 上下文
适用: 长 query (≥ 3 token) · 无模糊词 · 精确事实性问题
🔄 四级降级链
L0: PATH A 树浏览—失败→ L1: PATH B 精确检索—失败→ L2: Raw BM25 全量—失败→ L3: 空结果
前一步失败自动降级到下一步，不丢查询。L3 失败时返回空列表。
