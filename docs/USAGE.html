📖 Sisyphus 使用文档

安装

git clone https://github.com/Ask-Pillar/sisyphus.git
cd sisyphus
pip install -r requirements.txt
依赖: transformers torch jieba

MCP Server

启动 MCP Server (stdio 协议):

PYTHONPATH=src python3 -m sisyphus.server.mcp

在任何支持 MCP 的客户端配置中引用:

{
  "mcpServers": {
    "sisyphus": {
      "command": "python3",
      "args": ["-m", "sisyphus.server.mcp"],
      "env": {"PYTHONPATH": "src"}
    }
  }
}
支持的客户端: opencode、Claude Code、Cursor 等

MCP 工具

remember — 创建记忆

{
  "name": "remember",
  "arguments": {
    "title": "Python类型标注",
    "type": "lesson",
    "content": "使用Optional和List语法",
    "tags": ["python", "typing"],
    "importance": 7
  }
}

recall — 搜索记忆

{
  "name": "recall",
  "arguments": {
    "query": "Python类型标注语法",
    "top_k": 5
  }
}
返回双路径检索结果 (Path A 树浏览 / Path B 精确检索自动路由)

import — 一键导入 (P5 新增)

{
  "name": "import",
  "arguments": {
    "path": "/path/to/memories/"
  }
}
格式说明
.mdMarkdown 文件，支持 frontmatter
---
title: xxx
type: lesson
---
内容
.jsonl每行一个 JSON: {"title":"x","type":"lesson","content":"..."}
目录递归扫描 .md 和 .jsonl
去重: 相同 title 自动跳过，不覆盖已有记忆

其他工具

工具功能
forget删除记忆: {"id": "mem_xxx"}
list列出记忆: {"type": "lesson"}
run_pipelineSleep Pipeline: {"force": true, "use_llm": false}

CLI

# 记录记忆
PYTHONPATH=src python3 -m sisyphus.memory.cli record lesson "Python type hints"

# 搜索
PYTHONPATH=src python3 -m sisyphus.memory.cli search "type hints"

# 列出最近
PYTHONPATH=src python3 -m sisyphus.memory.cli recent

# 重建 Memory Tree
PYTHONPATH=src python3 -c "
from sisyphus.cli.tree_cmd import cmd_tree_rebuild
from pathlib import Path
cmd_tree_rebuild(Path.home() / '.omo' / 'memory')
"

生长测试

PYTHONPATH=src python3 docs/p5_gate.py      # Gate 测试 (30 queries)
PYTHONPATH=src python3 docs/p5_growth.py    # 生长测试 (4 stages)

文件结构

~/.omo/memory/
├── INDEX.md              ← MOC 主题地图入口
├── lesson/               ← RAW: 教训
├── pattern/              ← RAW: 模式
├── note/                 ← RAW: 笔记
├── refined/              ← REFINED: LLM 精炼
│   ├── reflection/       ← 洞察记录
│   ├── summary/          ← 退火摘要
│   └── loop/             ← 回路阻断
├── tree/                 ← Memory Tree
│   ├── _meta.json        ← 节点索引
│   ├── l0.json           ← 全局摘要
│   ├── l1/               ← type 聚类
│   └── l2/               ← 记忆叶子
└── logs/                 ← 审计日志

Reranker

BCE-Reranker (279M, CPU) 自动激活条件:

  • 同类型下记忆数 ≥ 8 条
  • 预期收益: +13% @1

无需手动配置，ContextRetriever._auto_reranker() 自动检测并加载。

环境要求

Python3.9+
磁盘~3GB (BCE 模型 ~1GB + 记忆文件)
CPUBCE 279M 无需 GPU
依赖jieba transformers torch
