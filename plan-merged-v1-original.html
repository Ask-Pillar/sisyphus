def _choose_path(query, moc_types):
    vague_words = {"关于","什么","了解","知道","介绍"}
    if len(query) < 15 or any(w in query for w in vague_words):
        return "A"  # 宽泛 → 树浏览
    if moc_types:
        return "B"  # MOC 精确命中 → 精确检索
    return "A"      # 默认树浏览
路径 A — 树浏览（宽泛 query）

路径 B — 精确检索（具体 query）
MOC 匹配→ EC 树剪枝→ DG Embedding→ CA3 BM25+余弦→ CA1 精排→ decay

#决策结论来源
1多客户端方案stdio 1:1，每客户端一个进程，不进 SSE评审 #3
2路径选择逻辑启发式：query 长度 + 模糊词 + MOC 匹配度，需 ABC 验证评审 #1
3无 LLM 树更新TreeBuilder title 拼接降级，树可构建，不退化评审 #2
4P0 命中率预期58-62%（纯安全改造，不改检索逻辑）评审 #4
5P3 gate 阈值≥80%，不达标不进 P4评审 #5
6WAL 配置journal_mode=WAL + wal_autocheckpoint=1000评审 #6
7向量存储SQLite blob（复用 CacheStore），不额外写 npy 文件评审 #7
8Sleep 触发RAW ≥ 20（原 v2 标准），v1 的 10 条阈值废弃评审次要
